# PricePulse AI — E-Commerce Price & Competitor Intelligence Tracker

PricePulse AI is an automated, high-performance SaaS platform built to track live product prices across major e-commerce retailers (Amazon, Flipkart), analyze market trends, and dispatch real-time pricing intelligence alerts.

## 🚀 Key Features
- **Automated Web Scraping:** Uses Playwright headless browser handling and BeautifulSoup4 to bypass basic bot-detection and parse accurate pricing data.
- **FastAPI Backend:** High-speed asynchronous API architecture powering product management and background tasks.
- **Executive SaaS Dashboard:** Responsive Bootstrap 5 UI displaying monitored items, real-time market prices, target thresholds, and status metrics.
- **Alert Dispatcher:** Automated notification system for price drops (Telegram & Webhook integration).

## 🛠️ Tech Stack
- **Backend:** Python, FastAPI, SQLAlchemy, SQLite
- **Scraping Engine:** Playwright, BeautifulSoup4
- **Frontend:** Bootstrap 5, HTML5, JavaScript
- **Environment:** Kali Linux, Uvicorn
